This module allows to modify a sale order line that contains a product
pack line that is locked for modification.

This can be useful if people needs to substitute a product by another
once without changing the pack configuration.

**Table of contents**

.. contents::
   :local:

Usage
=====

- Create a Sale Order with a pack product that forbid lines
  modifications.
- Add the user to the group that is allowed to modify lines.
- On the concerned sale order line, click on 'Modify' and choose the
  product that will replace the current one.
